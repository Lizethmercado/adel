# ADEL

Plataforma web con analítica de datos e inteligencia artificial generativa
para la gestión de compras e inventarios de mipymes de comidas rápidas
en Sincelejo.

## Stack tecnológico

- Frontend: React
- Backend: Node.js y Express (API REST)
- Base de datos: PostgreSQL con Prisma ORM
- Pruebas: Jest y Supertest
- Integración continua: GitHub Actions
