# Convenciones del Equipo (ADEL)

## Estrategia de Ramas (Gitflow)
* `main`: Código en producción. Solo recibe fusiones de `release/` o `hotfix/`.
* `develop`: Rama principal de integración.
* `feature/*`: Para historias y tareas.
* `release/*`: Para estabilizar antes de entregar.
* `hotfix/*`: Para correcciones urgentes.

## Prefijos de Commits
* `feat:` Nueva funcionalidad o historia.
* `fix:` Corrección de un error.
* `test:` Adición o cambio en pruebas.
* `docs:` Cambios en la documentación.
* `refactor:` Mejora del código sin cambiar su funcionalidad.
